# Orchicyb CRITICAL TWIN


## Overview

OrchiCyb Critical Twin is an experimental cybersecurity research platform exploring how **Cyber Threat Intelligence**, **Artificial Intelligence** and **Digital Twins** can transform the way we understand cyber attacks against critical infrastructure. Rather than analysing isolated alerts or static network diagrams, the platform creates an interactive digital representation of industrial environments where cyber attacks can be explored, visualised and understood in real time.

### Try the latest version: 
**https://orchicyb-critical-twin.lovable.app**
